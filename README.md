# Portafolio Web - Examen Parcial de Diseño Web (UCH)

Sitio web responsivo de portafolio personal desarrollado para el Examen Parcial del curso **Diseño Web** (ISI-FE2301, Semestre 2026-II).

## Tecnologías utilizadas
- **HTML5** semántico (`header`, `nav`, `main`, `section`, `footer`)
- **CSS3**: selectores `id` y `class`, cajas flotantes (`float` + `clear`), `transition`, `transform` y `@keyframes`
- **Multimedia**: `<audio>` local e `<iframe>` de YouTube
- **Diseño responsivo** con `@media` (< 768px y >= 768px)
- **SEO básico**: `title`, `description`, `keywords`, `viewport` y atributos `alt`
- **Git y GitHub Pages** para el control de versiones y la publicación

## Estructura
```
index.html
css/style.css
img/    (imágenes SVG)
media/  (audio local)
README.md
```
